# 🕌 Mosque Library Management System (مكتبة مسجد سعيد بن المسيب)

نظام ويب متكامل لإدارة مكتبة مسجد ومرافق الإقامة الجامعية، مصمم لتسهيل إدارة الكتب، تتبع الإعارات، تفعيل بوابات الطلاب، وتنظيم الأنشطة والمسابقات الأسبوعية.

## ✨ مميزات النظام:
* **بوابة الطالب:** تصفح الكتب، إعارة الكتب بمتابعة العد التنازلي، مشاركة خواطر القراء، ركن تبادل الكتب بين الغرف، وتقديم المقترحات والبلاغات السرية.
* **بوابة المشرفين:** لوحة تحكم إدارية كاملة لإدارة المخزون، متابعة الإعارات والمتأخرات، تتويج الفائزين في المسابقات، وتعديل جداول المداومات.
* **الربط السحابي:** يدعم التخزين المحلي (LocalStorage) والربط المباشر مع قاعدة بيانات Firebase للتحديث الفوري.
* **الرسوم البيانية:** إحصائيات بصرية تفاعلية لحركة الكتب والتصنيفات باستخدام Chart.js.

## 🛠️ التقنيات المستخدمة:
* **HTML5 / CSS3** (تصميم عصري متجاوب ويدعم اللغة العربية RTL)
* **JavaScript (Vanilla JS)** (إدارة الحالة والمنطق البرمجي)
* **Firebase Firestore** (قاعدة البيانات السحابية)
* **Chart.js** (الرسوم الإحصائية)
